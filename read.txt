Файл quiz.html — это интерактивный квиз на тему AI и программирования.

Общее описание:
quiz.html представляет собой автономный HTML-файл, содержащий интерактивный тест из 5 вопросов. Всё — структура, стили и логика — реализовано в одном файле без внешних библиотек. Квиз использует vanilla JavaScript, HTML и CSS. Интерфейс адаптирован под тёмную тему (#1a1a2e с акцентами #4facfe), как указано в правилах проекта.

Функциональность:
- Пользователю последовательно задаются 5 вопросов.
- На каждый вопрос можно выбрать один из предложенных вариантов.
- При выборе ответа:
  - Правильный ответ подсвечивается зелёным.
  - Неправильный — красным.
  - Появляется кнопка "Следующий вопрос".
- После последнего вопроса отображается итоговый экран с количеством правильных ответов.
- Можно начать квиз заново.
- В верхней части экрана отображаются:
  - Текущий номер вопроса (например, "Вопрос 3 / 5").
  - Количество набранных очков (по 1 баллу за верный ответ).

Техническая реализация:
- Структура: HTML с одним контейнером quiz-container.
- Стили: CSS встроен в тег <style>, использует цвета в соответствии с GIGACODE.md.
- Логика: JavaScript в теге <script>.
  - Вопросы хранятся в массиве questions.
  - Управление состоянием: currentQuestion, score, answered.
  - Функции: loadQuestion, selectAnswer, nextQuestion, showResult, restartQuiz.
  - Обновление счётчиков в реальном времени.
- Элементы интерфейса:
  - #question — текст вопроса.
  - #options — варианты ответов.
  - #next-btn — переход к следующему вопросу.
  - #result-screen — финальный экран с результатом.
  - #restart-btn — перезапуск квиза.
  - #question-counter и #score-counter — индикаторы прогресса.

Особенности:
- Полностью автономный — работает без сервера.
- Подходит для встраивания в документацию, обучение, демонстрации.
- Комментарии в коде — на русском языке.
- Соответствует правилам из GIGACODE.md.

Назначение:
Файл предназначен для проверки знаний по теме программирования и искусственного интеллекта в формате простого, но визуально привлекательного квиза.
